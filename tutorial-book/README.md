# Tutorial Book

This folder contains the tutorial book for the **FPGA Car Game** project.

The tutorial provides a step-by-step guide for implementing the project on the **DE10-Standard FPGA** using **Quartus Prime**. It includes project setup, hardware configuration, source code explanation, compilation, programming the FPGA board, and testing procedures.

The complete tutorial document is available in PDF format and can be downloaded directly from this folder.
