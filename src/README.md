# Source Code

This folder contains the main Verilog HDL source files used in the development of the **FPGA Car Game** project.

## Main Source Files
- `car_game.v` : Top-level module that integrates the entire game system.
- `render_static.v` : Graphics rendering module for the game display.
- `audio_top.v` : Audio controller module.
- `vga_640x480.v` : VGA display controller module with a resolution of 640×480.

## Complete Quartus Prime Project
The file `FPGA_CAR_GAME_Complete_Quartus_Project.zip` contains the complete Quartus Prime project, including:
- Verilog HDL source files.
- Quartus Prime project files (`.qpf` and `.qsf`).
- ROM files (`.mif`) and data files (`.hex`).
- IP configuration files.
- Other required project resources for compilation.

To run the project, simply download the ZIP file, extract its contents, and open the `.qpf` file using Quartus Prime. All required source files and project configurations are included, allowing the project to be compiled and executed successfully.
